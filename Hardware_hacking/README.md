# Hardware Hacking

By this I mean developing or creating new hardware to interface with my jukebox.  This is enabled by understanding the communication protocol(s) used by the jukebox to interface with external devices.

At this point, these are only brainstormed ideas, such as:
- Use a laptop (or Arduino, or R-pi) to function as an "InterROWEgator" device.  It would receive the data-dump that the jukebox provides (by using service code 800) and summarizes or outputs the data in a useful way.  This could take a form similar to the paper strip printout generated by the legacy InterROWEgator device, or potentially include much more detailed data about the state of the jukebox (settings, MEMOREC data, etc.).
- Connect a device to the wallbox line.
